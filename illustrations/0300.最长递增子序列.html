最长递增子序列，以谁结尾

dp[i] 记以 nums[i] 结尾的最长递增子序列长度。nums[i] 可以接在前面任何一个比它小的数后面，接在哪个后面最长，就选哪个。

分层提示

提示 1定义状态要带上结尾点开

只说「前 i 个数的 LIS 长度」没法转移，因为不知道最后一个数是多少，新数接不接得上。

改成 dp[i]：以 nums[i] 结尾的最长递增子序列长度。

提示 2转移点开

对所有 j < i 且 nums[j] < nums[i]，dp[i] = max(dp[j] + 1)。没有这样的 j 时 dp[i] = 1。

答案是 max(dp)，不是 dp[-1]。

提示 3进阶：O(n log n)点开

维护 tails[k]：长度为 k + 1 的递增子序列里，结尾最小是多少。tails 是递增的。

每来一个数 x，二分找到第一个 ≥ x 的位置替换掉；没有就接在末尾。最后 tails 的长度就是答案。

代码标准解法：动态规划 O(n²)点开 
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        dp = [1] * len(nums)                # dp[i]：以 nums[i] 结尾的 LIS 长度
        for i in range(len(nums)):
            for j in range(i):
                if nums[j] < nums[i]:
                    dp[i] = max(dp[i], dp[j] + 1)   # 接在 nums[j] 后面
        return max(dp)
代码简洁写法：贪心 + 二分 O(n log n)点开

tails[k:k+1] = [x]：k 等于长度时相当于 append，否则替换掉更大的结尾。

from bisect import bisect_left

class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        tails = []                          # tails[k]：长度 k+1 的递增子序列的最小结尾
        for x in nums:
            k = bisect_left(tails, x)       # 第一个 >= x 的位置
            tails[k:k + 1] = [x]            # k 等于长度时是接在最后，否则是替换
        return len(tails)
