LeetCode 19 · 中等 · 链表

删除倒数第 N 个结点，让两个指针保持固定的距离

链表不知道长度，也不能倒着走。让 fast 先走 n 步，然后 fast 和 slow 一起走。fast 走到最后一个节点时，slow 正好停在要删除的节点前面。

分层提示

提示 1最直接的做法点开

先走一遍数出长度 L，倒数第 n 个就是正数第 L − n + 1 个，再走一遍去删。需要走两遍。

提示 2一遍怎么做点开

让 fast 比 slow 领先 n 步，然后同时走。

fast 到最后一个节点时，slow 后面正好还有 n 个节点，也就是 slow.next 是倒数第 n 个。

提示 3为什么需要哑节点点开

删除一个节点要改的是它前一个节点的指针。

如果要删的是头节点，它没有前一个节点。在头节点前面加一个 dummy，所有情况就都一样了。

代码标准解法：哑节点 + 快慢指针点开 
class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        slow = fast = dummy
        for _ in range(n):              # fast 先走 n 步
            fast = fast.next
        while fast.next:                # 一起走，直到 fast 在最后一个节点
            slow = slow.next
            fast = fast.next
        slow.next = slow.next.next      # 跳过要删的节点
        return dummy.next
代码简洁写法：递归数倒数第几个点开

递归返回时自然是从尾往头，返回值就是「倒数第几个」。数到倒数第 n + 1 个时，删掉它后面那个。

class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        def rec(node):
            if not node:
                return 0
            k = rec(node.next) + 1
            if k == n + 1:
                node.next = node.next.next
            return k
        dummy = ListNode(0, head)
        rec(dummy)
        return dummy.next
