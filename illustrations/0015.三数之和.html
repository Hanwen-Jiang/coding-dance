LeetCode 15 · 中等 · 双指针

三数之和，排序后固定一个，剩下两个对撞

先排序。固定最小的那个数，剩下的问题就是在它右边找两个数凑出指定的和，用对撞双指针一遍就能找完。去重也靠排序：相同的数挨在一起，跳过就行。

分层提示

提示 1先排序点开

题目返回的是数值不是下标，所以可以排序。

排序后有两个好处：可以用双指针，以及重复的数会挨在一起，方便跳过。

提示 2固定一个，找两个点开

枚举第一个数 nums[i]，在它右边用 l、r 两个指针找和为 -nums[i] 的两个数。

三数之和太小就 l 右移，太大就 r 左移。

提示 3怎么去重点开

第一个数：nums[i] 和前一个相同就跳过，否则会得到一模一样的三元组。

找到一组答案后：l 和 r 都要跳过和刚才相同的值。

代码标准解法：排序 + 双指针点开 
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        n, res = len(nums), []
        for i in range(n - 2):
            if nums[i] > 0:
                break                   # 最小的都大于 0，后面不可能了
            if i > 0 and nums[i] == nums[i - 1]:
                continue                # 第一个数去重
            l, r = i + 1, n - 1
            while l < r:
                s = nums[i] + nums[l] + nums[r]
                if s < 0:
                    l += 1
                elif s > 0:
                    r -= 1
                else:
                    res.append([nums[i], nums[l], nums[r]])
                    l += 1
                    r -= 1
                    while l < r and nums[l] == nums[l - 1]:
                        l += 1          # 第二个数去重
                    while l < r and nums[r] == nums[r + 1]:
                        r -= 1          # 第三个数去重
        return res

写代码时注意

去重有三处

第一个数、第二个数、第三个数都要跳过重复值。漏掉任何一处都会出现重复的三元组。

i > 0 才比较前一个

nums[i] == nums[i-1] 之前要先判断 i > 0，否则 i = 0 时会和最后一个数比。

复杂度

排序 O(n log n)，外层枚举 n 次、内层双指针 O(n)，总共 O(n²)。
