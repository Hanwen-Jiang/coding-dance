LeetCode 114 · 中等 · 二叉树

二叉树展开为链表，把左子树插到右边

展开后的顺序是前序遍历。对当前节点：如果有左子树，就把原来的右子树接到左子树最右边的节点后面，再把整个左子树挪到右边。然后沿右指针往下走，重复这个过程。

分层提示

提示 1目标顺序点开

展开后的链表按前序（根 → 左 → 右）排列，全部用 right 指针串起来，left 都是空。

提示 2一个节点怎么处理点开

节点 cur 有左子树时：左子树里前序最后一个节点，就是左子树最右边的节点 pre。

原来的右子树应该接在 pre 后面：pre.right = cur.right。然后 cur.right = cur.left，cur.left = None。

提示 3往下走点开

处理完 cur 后走到 cur.right，继续同样的处理，直到走到空。整个过程只用 O(1) 额外空间。

代码标准解法：原地挪左子树点开 
class Solution:
    def flatten(self, root: Optional[TreeNode]) -> None:
        cur = root
        while cur:
            if cur.left:
                pre = cur.left
                while pre.right:            # 左子树最右边的节点
                    pre = pre.right
                pre.right = cur.right       # 原来的右子树接到它后面
                cur.right = cur.left        # 左子树挪到右边
                cur.left = None             # 断开左指针
            cur = cur.right
代码简洁写法：反向前序点开

按 右 → 左 → 根 的顺序访问，正好是前序倒过来，也就是从链表尾往头。每个节点接上一个访问的节点就行。

class Solution:
    def flatten(self, root: Optional[TreeNode]) -> None:
        prev = None
        def dfs(node):
            nonlocal prev
            if node:
                dfs(node.right)
                dfs(node.left)
                node.right = prev
                node.left = None
                prev = node
        dfs(root)

写代码时注意

先接右子树再挪左子树

顺序反了的话，原来的右子树会丢掉。

left 要置空

题目要求左指针都是 null，挪完后记得 cur.left = None。

复杂度

每个节点最多被当成 pre 走过一次，时间 O(n)，空间 O(1)。
