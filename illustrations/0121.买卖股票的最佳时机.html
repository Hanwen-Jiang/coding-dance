买卖股票，在之前最便宜的那天买

假设今天卖出，那么最好的买入日就是今天之前价格最低的那天。从左往右走，一边记住到目前为止的最低价，一边算今天卖能赚多少，取最大值。

分层提示

提示 1固定卖出的那天点开

如果第 i 天卖出，最多能赚 prices[i] - min(prices[0..i])。

把每一天都当一次卖出日，取最大值就是答案。

提示 2最低价不用每次重新算点开

从左往右走时，用一个变量 min_price 记住走过的最低价，每天更新一次。

提示 3不赚钱就不交易点开

价格一直下跌时，每天卖出都是亏的。答案初始为 0，相当于不交易。

代码标准解法：一次遍历点开 
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        min_price, best = float("inf"), 0
        for p in prices:
            min_price = min(min_price, p)       # 到今天为止的最低价
            best = max(best, p - min_price)     # 今天卖出能赚多少
        return best
代码简洁写法：前缀最小值点开

accumulate(prices, min) 生成每一天之前（含当天）的最低价。

from itertools import accumulate

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        return max(p - m for p, m in zip(prices, accumulate(prices, min)))

写代码时注意

先更新最低价再算利润

两句顺序反过来也对，因为当天买当天卖利润是 0，不会影响答案。

不能先卖后买

所以不能直接用「最大值 − 最小值」，最小值必须出现在最大值之前。

复杂度

一遍扫描，时间 O(n)，空间 O(1)。
