两两交换链表中的节点，每次改三根指针

每次处理一对相邻的节点。站在这一对的前一个节点上，改三根指针就能把它们换过来，然后跳到下一对前面。用哑节点让第一对也有「前一个节点」。

分层提示

提示 1交换一对需要知道什么点开

要交换 a 和 b，光有它们俩不够，还要知道 a 前面的节点 prev，因为 prev.next 要从 a 改成 b。

提示 2三根指针点开

原来：prev → a → b → 后面。目标：prev → b → a → 后面。

prev.next = b；a.next = b.next；b.next = a。

提示 3下一对从哪开始点开

交换后 a 在这一对的后面，它正好是下一对的前一个节点，所以 prev = a。

剩下不足两个节点时停止。

代码标准解法：哑节点 + 迭代点开 
class Solution:
    def swapPairs(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        prev = dummy
        while prev.next and prev.next.next:
            a, b = prev.next, prev.next.next
            prev.next, a.next, b.next = b, b.next, a   # 三根指针一起改
            prev = a                    # a 现在在后面，是下一对的前驱
        return dummy.next
代码简洁写法：递归点开

交换前两个，第一个的后面接上「从第三个开始两两交换的结果」。

class Solution:
    def swapPairs(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next:
            return head
        nxt = head.next
        head.next = self.swapPairs(nxt.next)
        nxt.next = head
        return nxt

写代码时注意

指针赋值的顺序

分三行写时，要先用掉 b.next 再改它。Python 的多重赋值会先算完右边再赋值，可以写成一行。

循环条件

prev.next and prev.next.next：后面至少有两个节点才交换。

不要只交换值

题目要求真的交换节点，不能只改节点里的值。
