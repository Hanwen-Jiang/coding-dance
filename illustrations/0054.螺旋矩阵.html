LeetCode 54 · 中等 · 矩阵

螺旋矩阵，四条边界一圈圈往里收

用上、下、左、右四个边界框住还没走过的部分。沿着上边走完，上边界就往下收一行；沿着右边走完，右边界就往左收一列。这样一圈圈收下去，直到边界交错。

分层提示

提示 1用边界代替方向判断点开

不用记「走过哪些格子」。维护 top、bottom、left、right 四个边界，它们围住的是还没走的区域。

提示 2一圈分四段点开

上边：从左到右，走完 top += 1。

右边：从上到下，走完 right -= 1。

下边：从右到左，走完 bottom -= 1。左边：从下到上，走完 left += 1。

提示 3只剩一行或一列时点开

走完上边和右边后，区域可能已经空了。

所以走下边之前要检查 top <= bottom，走左边之前要检查 left <= right，否则会把同一行或同一列再走一遍。

代码标准解法：收缩边界点开 
class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        res = []
        top, bottom = 0, len(matrix) - 1
        left, right = 0, len(matrix[0]) - 1
        while top <= bottom and left <= right:
            for j in range(left, right + 1):        # 上边：左 -> 右
                res.append(matrix[top][j])
            top += 1
            for i in range(top, bottom + 1):        # 右边：上 -> 下
                res.append(matrix[i][right])
            right -= 1
            if top <= bottom:
                for j in range(right, left - 1, -1):    # 下边：右 -> 左
                    res.append(matrix[bottom][j])
                bottom -= 1
            if left <= right:
                for i in range(bottom, top - 1, -1):    # 左边：下 -> 上
                    res.append(matrix[i][left])
                left += 1
        return res
代码简洁写法：取走第一行，再把剩下的转一下点开

每次拿走第一行，把剩下的矩阵逆时针转 90°，新的第一行就是原来的右边一列。会改掉输入，时间 O((m·n)·min(m, n))。

class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        res = []
        while matrix:
            res += matrix.pop(0)
            matrix = [list(r) for r in zip(*matrix)][::-1]
        return res

写代码时注意

两个 if 不能省

只有一行或一列的矩阵，少了这两个检查就会输出重复的数。

走完立刻收边界

每走完一条边就马上更新对应的边界，下一条边的起点自然避开了拐角。

复杂度

每个格子走一次，时间 O(m · n)。
