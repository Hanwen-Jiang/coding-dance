LeetCode 64 · 中等 · 多维动态规划

最小路径和，上面和左边挑小的

和不同路径一样，到达 (i, j) 的上一步只能在上面或左边。走到这里的最小路径和，就是这两个格子的最小路径和里较小的那个，再加上自己。

分层提示

提示 1定义状态点开

dp[i][j]：从左上角走到 (i, j) 的最小路径和。

提示 2转移点开

dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]。

第一行只能从左边来，第一列只能从上面来，要单独处理。

提示 3压成一行点开

按行更新时，dp[j] 更新前存的是上一行的值（上面），dp[j-1] 已经是这一行的值（左边）。一行数组就够了。

代码标准解法：二维 DP点开 
class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        dp = [[0] * n for _ in range(m)]
        for i in range(m):
            for j in range(n):
                if i == 0 and j == 0:
                    dp[i][j] = grid[0][0]
                elif i == 0:
                    dp[i][j] = dp[i][j - 1] + grid[i][j]    # 第一行只能从左边来
                elif j == 0:
                    dp[i][j] = dp[i - 1][j] + grid[i][j]    # 第一列只能从上面来
                else:
                    dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]
        return dp[-1][-1]
代码简洁写法：一行滚动（空间压缩）点开

只留一行 dp。初始化成 inf 代表越界的第 -1 行（走不过来），只让 dp[0] = 0 作为起点的「上面」；j = 0 时左边越界也取 inf。这样第一行、第一列都不用特判。空间 O(n)。

from math import inf

class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        dp = [inf] * len(grid[0])       # 第 -1 行：越界，走不过来，全是 ∞
        dp[0] = 0                       # 只有起点的「上面」当成 0
        for row in grid:
            for j, x in enumerate(row):
                dp[j] = min(dp[j], dp[j - 1] if j else inf) + x  # 上面 dp[j]，左边 dp[j-1]（j = 0 越界取 ∞）
        return dp[-1]

写代码时注意

边界单独处理

第一行和第一列只有一个来源。用 inf 填充边界也可以省掉特判。

可以原地修改

直接把 grid 当 dp 用，空间 O(1)，但会改掉输入。

复杂度

时间 O(m·n)，一行滚动时空间 O(n)。
