## 怎么新增或修改图解

除 200、215、236 三份是手写的以外，其余页面都由 `tools/illustrations/` 生成：每题一份 `specs/<编号>.js`，运行 `node tools/illustrations/build.js [题号...]` 生成 HTML。构建时会自动跑一遍每个演示并核对答案，也会用测试用例运行页面里的每段 Python 代码。
