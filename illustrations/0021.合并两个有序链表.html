合并两个有序链表，每次接上较小的那个

两个链表都已经排好序，所以最小的数一定在某个链表的头上。每次比较两个头，把小的那个接到结果后面，再让那个链表往前走一步。

分层提示

提示 1每次只看两个头点开

两个链表各有一个指针。比较它们指向的值，小的那个就是剩下所有数里最小的。

提示 2用一个假的头节点点开

结果链表的第一个节点是谁，一开始不知道。

先建一个 dummy 节点，所有节点都接在它后面，最后返回 dummy.next，这样不用单独处理第一个节点。

提示 3一个链表先走完点开

其中一个走完后，另一个剩下的部分已经是有序的，直接整段接上，不用再一个个比。

代码标准解法：迭代 + 哑节点点开 
class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = cur = ListNode()
        while list1 and list2:
            if list1.val <= list2.val:
                cur.next, list1 = list1, list1.next
            else:
                cur.next, list2 = list2, list2.next
            cur = cur.next
        cur.next = list1 or list2       # 剩下的整段接上
        return dummy.next
代码简洁写法：递归点开

让 list1 始终指向较小的头，它的后面接上「剩下部分的合并结果」。

class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        if not list1 or not list2:
            return list1 or list2
        if list1.val > list2.val:
            list1, list2 = list2, list1
        list1.next = self.mergeTwoLists(list1.next, list2)
        return list1

写代码时注意

返回 dummy.next

dummy 本身只是占位用的，真正的头是它的下一个节点。

相等时取哪个都行

用 <= 让相等时先取 list1 的，结果是稳定的。

复杂度

时间 O(m + n)，空间 O(1)，没有新建节点，只是改指针。
