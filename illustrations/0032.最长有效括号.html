最长有效括号，栈底放分界线

用栈存下标。左括号的下标入栈等待匹配；右括号来了就弹出一个。栈底始终放着「最后一个没被匹配的位置」，当前位置减去栈顶，就是以这里结尾的有效括号长度。

分层提示

提示 1栈里放下标点开

遇到 ( 把下标压栈；遇到 ) 弹出栈顶，表示匹配了一对。

要算长度，所以存下标而不是字符。

提示 2栈底放一个分界线点开

一开始压入 -1。弹出后栈不空，i - stack[-1] 就是以 i 结尾的有效长度。

弹出后栈空了，说明这个 ) 没人匹配，它成了新的分界线，把 i 压进去。

提示 3也可以不用栈点开

从左往右数左右括号个数，相等时更新答案，右括号多了就清零。

再从右往左数一遍，处理 (() 这种左括号一直多的情况。

代码标准解法：栈点开 
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        stack, best = [-1], 0               # 栈底：最后一个没匹配上的位置
        for i, c in enumerate(s):
            if c == "(":
                stack.append(i)
            else:
                stack.pop()
                if not stack:               # 这个 ) 没人匹配，成为新的分界线
                    stack.append(i)
                else:
                    best = max(best, i - stack[-1])
        return best
代码简洁写法：左右各数一遍点开

反过来扫描时把 ) 当成开括号，逻辑完全一样。空间 O(1)。

class Solution:
    def longestValidParentheses(self, s: str) -> int:
        def scan(s, opener):
            best = l = r = 0
            for c in s:
                if c == opener:
                    l += 1
                else:
                    r += 1
                if l == r:
                    best = max(best, 2 * r)
                elif r > l:
                    l = r = 0
            return best
        return max(scan(s, "("), scan(s[::-1], ")"))

写代码时注意

先弹再判空

遇到 ) 先 pop。pop 之后栈空，说明弹出的是分界线，这个 ) 无法匹配。

长度用栈顶算

不是 i − 弹出的下标 + 1，而是 i − 新的栈顶。这样能把连在一起的几段有效括号一起算上。

复杂度

每个下标最多进出栈一次，时间 O(n)，空间 O(n)。双向扫描写法空间 O(1)。
