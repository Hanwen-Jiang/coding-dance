电话号码的字母组合，一位一位地选

每个数字对应几个字母，要列出所有的选法。做法是一位一位往下选：第一位选一个字母，接着选第二位，选满了就记下来。然后退回一步，把刚才那一位换成下一个字母，再继续。这种「选一个、往下走、退回来换一个」的过程就是回溯。

分层提示

提示 1把它想成一棵树点开

第一层是第一个数字的几个字母，每个字母下面再分出第二个数字的几个字母。

从根走到叶子的每一条路，就是一个组合。

提示 2递归函数管什么点开

dfs(i)：现在该为第 i 个数字选字母了。

i 等于数字的个数时，说明每一位都选好了，把当前路径记进结果。

提示 3回溯的三步点开

选：把一个字母放进路径。

往下：dfs(i + 1)。

撤销：把这个字母从路径里拿出来，换下一个字母再试。

代码标准解法：回溯点开 
class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        if not digits:
            return []
        phone = {"2": "abc", "3": "def", "4": "ghi", "5": "jkl",
                 "6": "mno", "7": "pqrs", "8": "tuv", "9": "wxyz"}
        res, path = [], []
        def dfs(i):
            if i == len(digits):
                res.append("".join(path))
                return
            for ch in phone[digits[i]]:
                path.append(ch)         # 选
                dfs(i + 1)              # 往下
                path.pop()              # 撤销
        dfs(0)
        return res
代码简洁写法：笛卡尔积点开

每个数字对应一组字母，所有组合就是这几组字母的笛卡尔积。

from itertools import product

class Solution:
    def letterCombinations(self, digits: str) -> List[str]:
        if not digits:
            return []
        m = {"2": "abc", "3": "def", "4": "ghi", "5": "jkl",
             "6": "mno", "7": "pqrs", "8": "tuv", "9": "wxyz"}
        return ["".join(p) for p in product(*(m[d] for d in digits))]

写代码时注意

空字符串

digits 为空时要返回 []。不特判的话会得到 [""]。

撤销不能少

path.pop() 把这一位清掉，下一个字母才能放在同一个位置上。

复杂度

每位有 3 或 4 种选择，组合数最多 4ⁿ 个，每个组合长 n，时间 O(n · 4ⁿ)。
