接雨水，每一格能接多少只看两边最高的柱子

某一格上方的水位，等于它左边最高柱子和右边最高柱子里较矮的那个。用两个指针从两端往中间走，哪边的最高值更小，哪边那一格的水量就已经能确定。

分层提示

提示 1先只看一格点开

下标 i 这一格能接的水 = min(左边最高, 右边最高) − height[i]。

水位由两边最高的柱子里矮的那个决定，再减掉这一格自己的高度。

提示 2朴素做法点开

预先算出每个位置的左边最高 leftMax[i] 和右边最高 rightMax[i]，再逐格相加。时间 O(n)，空间 O(n)。

提示 3省掉两个数组点开

用 l、r 从两端往中间走，同时维护 leftMax、rightMax。

如果 leftMax < rightMax，那么 l 这一格的水位一定是 leftMax：右边至少有一根柱子不低于它。这一格算完，l 右移。另一边同理。

代码标准解法：双指针点开 
class Solution:
    def trap(self, height: List[int]) -> int:
        l, r = 0, len(height) - 1
        left_max = right_max = 0
        water = 0
        while l < r:
            left_max = max(left_max, height[l])
            right_max = max(right_max, height[r])
            if left_max < right_max:    # 左边矮，l 这一格水位就是 left_max
                water += left_max - height[l]
                l += 1
            else:
                water += right_max - height[r]
                r -= 1
        return water
代码简洁写法：前缀最大值点开

每个位置能接的水 = min(左边最高, 右边最高) − 自己的高度。用 accumulate 一次算出两个方向的最高。

from itertools import accumulate

class Solution:
    def trap(self, height: List[int]) -> int:
        left = accumulate(height, max)
        right = list(accumulate(reversed(height), max))[::-1]
        return sum(min(l, r) - h for l, r, h in zip(left, right, height))
代码另一种写法：单调栈，按层接水点开

栈里的柱子从底到顶越来越矮。来了一根更高的柱子，栈顶就是一个坑的坑底，它下面那根是左墙，新柱子是右墙，一次接上一层水。

class Solution:
    def trap(self, height: List[int]) -> int:
        stack, water = [], 0                # 栈里存下标，高度从底到顶递减
        for i, h in enumerate(height):
            while stack and height[stack[-1]] < h:
                bottom = stack.pop()        # 坑底
                if not stack:
                    break                   # 左边没有墙，接不住
                left = stack[-1]
                width = i - left - 1
                water += (min(height[left], h) - height[bottom]) * width
            stack.append(i)
        return water
