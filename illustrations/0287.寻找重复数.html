寻找重复数，把数组当成链表找环

数组有 n + 1 个数，值都在 1 到 n 之间。把下标 i 看成一个节点，nums[i] 看成它指向的下一个节点。有两个下标指向同一个值，这个值就是环的入口。剩下的就和环形链表 II 一模一样：快慢指针相遇后，一个从头走，再次相遇的地方就是入口。

分层提示

提示 1换一个角度看数组点开

从下标 0 出发，不断走 i → nums[i]。因为值都在 1..n，永远不会走出数组，也永远不会回到 0。

n + 1 个下标、只有 n 种值，一定会走进一个环。

提示 2重复的数就是环的入口点开

重复的数 d 被两个不同的下标指向，所以 d 这个节点有两条入边，一条来自环外、一条来自环内，它就是环的入口。

提示 3Floyd 判圈点开

慢指针每次走一步，快指针每次走两步，直到相遇。

然后让一个指针回到起点 0，两个指针每次都走一步，再次相遇的位置就是入口。证明同第 142 题。

代码标准解法：快慢指针找环入口点开 
class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        slow = fast = 0
        while True:                         # 把 i -> nums[i] 看成链表
            slow = nums[slow]
            fast = nums[nums[fast]]
            if slow == fast:
                break
        slow = 0                            # 一个回到起点，再同速走
        while slow != fast:
            slow = nums[slow]
            fast = nums[fast]
        return slow                         # 相遇点就是环的入口
代码简洁写法：对值二分点开

设重复数是 d。≤ x 的数的个数，在 x < d 时不超过 x，在 x ≥ d 时超过 x。二分找第一个超过的 x。时间 O(n log n)。

from bisect import bisect_left

class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        return bisect_left(range(len(nums)), True, key=lambda x: sum(v <= x for v in nums) > x)

写代码时注意

从下标 0 出发

值都在 1..n，没有任何下标指向 0，所以 0 一定在环外，是链表的「头」。

不修改数组

题目要求不修改、O(1) 空间，所以不能排序，也不能用原地标记的方法。

复杂度

快慢指针时间 O(n)，空间 O(1)。
