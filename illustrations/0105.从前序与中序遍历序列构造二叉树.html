LeetCode 105 · 中等 · 二叉树

前序 + 中序建树，前序定根，中序分左右

前序遍历的第一个数一定是根。在中序遍历里找到这个根，它左边的都属于左子树，右边的都属于右子树，于是也知道了左子树有几个节点，前序里对应的两段也就切出来了。两边递归。

分层提示

提示 1谁是根点开

前序遍历是 根 → 左 → 右，所以 preorder[0] 是根。

提示 2怎么分左右点开

在中序遍历（左 → 根 → 右）里找到根的位置 k。

inorder[:k] 是左子树，inorder[k+1:] 是右子树。左子树有 k 个节点。

前序里根后面紧跟着的 k 个数是左子树，剩下的是右子树。

提示 3怎么写得快点开

用哈希表记下每个值在中序里的下标，找根变成 O(1)。

递归时传区间的下标，不要切片复制数组。

代码标准解法：递归 + 哈希表定位点开 
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        idx = {v: i for i, v in enumerate(inorder)}    # 值 -> 中序下标

        def build(pl, pr, il, ir):          # 前序 [pl, pr)，中序 [il, ir)
            if pl == pr:
                return None
            root = TreeNode(preorder[pl])   # 前序第一个是根
            k = idx[root.val]
            left_size = k - il              # 中序里根左边的都是左子树
            root.left = build(pl + 1, pl + 1 + left_size, il, k)
            root.right = build(pl + 1 + left_size, pr, k + 1, ir)
            return root

        return build(0, len(preorder), 0, len(inorder))
代码简洁写法：切片递归点开

切片和 index 让每层多了 O(n) 的开销，最坏 O(n²)，但写起来最直观。

class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        if not preorder:
            return None
        k = inorder.index(preorder[0])
        return TreeNode(preorder[0],
                        self.buildTree(preorder[1:k + 1], inorder[:k]),
                        self.buildTree(preorder[k + 1:], inorder[k + 1:]))

写代码时注意

左子树大小是关键

left_size = k − il。前序里左子树的范围是 [pl+1, pl+1+left_size)，算错一位整棵树就错了。

值不重复

题目保证值互不相同，哈希表定位才是唯一的。

复杂度

哈希表写法每个节点 O(1)，总共 O(n)；递归深度是树高。
