最长回文子串，从每个中心向两边扩

回文串是左右对称的，所以可以从中间往两边看：只要两边的字符相同，就能继续往外扩。把每个位置都当一次中心试一遍，记下能扩到的最长的那一段。

分层提示

提示 1从中心往外看点开

如果 s[l..r] 是回文，并且 s[l−1] == s[r+1]，那么 s[l−1..r+1] 也是回文。

所以从一个中心出发，不断比较两边的字符，能扩多远就扩多远。

提示 2中心有两种点开

奇数长度的回文（如 aba）中心是一个字符。

偶数长度的回文（如 abba）中心是两个字符之间的缝。两种都要试，一共 2n − 1 个中心。

提示 3和动态规划的关系点开

动态规划的写法是 dp[l][r] = (s[l] == s[r]) and dp[l+1][r−1]，判断每一段是不是回文。

中心扩展用的是同一个递推关系，只是不用存整张表，空间从 O(n²) 降到 O(1)。

代码标准解法：中心扩展点开 
class Solution:
    def longestPalindrome(self, s: str) -> str:
        def expand(l, r):
            while l >= 0 and r < len(s) and s[l] == s[r]:
                l -= 1
                r += 1
            return l + 1, r - 1         # 退回最后一次成功的位置

        start = end = 0
        for i in range(len(s)):
            for l, r in (expand(i, i), expand(i, i + 1)):   # 奇数中心、偶数中心
                if r - l > end - start:
                    start, end = l, r
        return s[start:end + 1]
代码动态规划写法点开

dp[l][r] 表示 s[l..r] 是不是回文。按长度从短到长填表。

class Solution:
    def longestPalindrome(self, s: str) -> str:
        n = len(s)
        dp = [[False] * n for _ in range(n)]
        start, size = 0, 1
        for length in range(1, n + 1):
            for l in range(n - length + 1):
                r = l + length - 1
                if s[l] == s[r] and (length <= 2 or dp[l + 1][r - 1]):
                    dp[l][r] = True
                    if length > size:
                        start, size = l, length
        return s[start:start + size]
代码简洁写法：所有中心扩一遍，取最长点开

每个位置 i 有两个中心：(i, i) 是奇数长度，(i, i+1) 是偶数长度。

class Solution:
    def longestPalindrome(self, s: str) -> str:
        def grow(l, r):
            while l >= 0 and r < len(s) and s[l] == s[r]:
                l, r = l - 1, r + 1
            return s[l + 1:r]
        return max((grow(i, j) for i in range(len(s)) for j in (i, i + 1)), key=len)
