字符串解码，遇到 [ 先存档，遇到 ] 再展开

括号可以嵌套，所以要先解开里面的。从左往右扫：遇到 [ 时，把括号外已经拼好的前缀和重复次数压栈，开始拼括号里的内容；遇到 ] 时，弹出存档，把括号里的内容重复若干次接到前缀后面。

分层提示

提示 1需要记住什么点开

遇到 [ 时，括号外面已经有一段拼好的字符串 cur，还有括号前的数字 k。

这两样都要先存起来，等括号里的内容解完再用。

提示 2用栈存档点开

[：把 (cur, k) 压栈，cur 清空，k 清零。

]：弹出 (prev, times)，cur = prev + cur * times。

字母直接接到 cur 后面。

提示 3数字可能不止一位点开

比如 100[a]。读数字时要 k = k * 10 + int(c)。

代码标准解法：栈点开 
class Solution:
    def decodeString(self, s: str) -> str:
        stack, cur, k = [], "", 0
        for c in s:
            if c.isdigit():
                k = k * 10 + int(c)         # 数字可能不止一位
            elif c == "[":
                stack.append((cur, k))      # 存档：括号外的前缀和重复次数
                cur, k = "", 0
            elif c == "]":
                prev, times = stack.pop()
                cur = prev + cur * times    # 展开后接回前缀
            else:
                cur += c
        return cur
代码简洁写法：正则反复展开最内层点开

「数字[纯字母]」一定是最内层的括号，替换掉它，直到没有括号为止。

import re

class Solution:
    def decodeString(self, s: str) -> str:
        inner = re.compile(r"(\d+)\[([a-z]*)\]")
        while "[" in s:
            s = inner.sub(lambda m: m[2] * int(m[1]), s)
        return s
