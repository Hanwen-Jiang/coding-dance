二叉树的最近公共祖先，让答案自己往上冒

每个节点只问左右子树一句话：你们那边找到 p 或 q 了吗？左右都说找到了，自己就是答案。下面的树可以逐步播放递归过程，每个节点下面会挂出它向上返回的东西。

分层提示

提示 1先定好递归函数返回什么点开

让函数 f(node) 回答：在以 node 为根的这棵子树里，有没有找到 p 或 q？

找到了就把找到的节点交上来，什么都没找到就返回空。

提示 2拿到左右两边的回答后怎么办点开

左右都不为空：p 和 q 分别在两侧，当前节点就是最近公共祖先，返回自己。

只有一边不为空：把那一边的结果原样往上交。它可能是 p 或 q，也可能是下面已经找到的答案。

都为空：这棵子树里什么都没有，返回空。

提示 3碰到 p 为什么可以直接返回点开

走到 p 时，不用再往下找 q。如果 q 在 p 下面，答案就是 p 自己；如果 q 不在 p 下面，别的分支会找到 q，在上面汇合。

这一步依赖题目保证 p、q 都在树里。演示里的示例 2 就是 q 在 p 下面的情况，可以看看 4 根本没被访问到。

代码标准解法：后序递归点开 
class Solution:
    def lowestCommonAncestor(self, root, p, q):
        if root is None or root is p or root is q:
            return root                 # 空，或者就是要找的节点
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)
        if left and right:
            return root                 # p、q 分在两边
        return left or right            # 哪边有就交哪边
代码不用递归：记录父节点点开

先遍历一遍记下每个节点的父节点，再从 p 一路往上把祖先都放进集合，最后从 q 往上走，第一个在集合里的就是答案。树退化成一条长链时，递归写法在 Python 里可能超过默认的递归深度上限，这个写法没有这个问题。

class Solution:
    def lowestCommonAncestor(self, root, p, q):
        parent = {root: None}
        stack = [root]
        while p not in parent or q not in parent:
            node = stack.pop()
            for child in (node.left, node.right):
                if child:
                    parent[child] = node
                    stack.append(child)
        ancestors = set()
        while p:                        # p 和它所有的祖先
            ancestors.add(p)
            p = parent[p]
        while q not in ancestors:       # q 往上走，第一个碰到的就是答案
            q = parent[q]
        return q
