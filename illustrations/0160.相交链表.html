LeetCode 160 · 简单 · 链表

相交链表，走完自己的路再走对方的路

两个链表长度不同，所以两个指针同时出发不会同时到达交点。让每个指针走完自己的链表后，接着从对方的头开始走。这样两个指针走的总长度相同，会同时到达交点。

分层提示

提示 1为什么直接走不行点开

如果两个链表在交点之前的长度一样，两个指针同时走就会同时到交点。

问题是前面的长度可能不同，要想办法把这个差距抹掉。

提示 2把两段路拼起来点开

设 A 独有的部分长 a，B 独有的部分长 b，公共部分长 c。

指针 pa 走 A 再走 B：a + c + b 步到交点。指针 pb 走 B 再走 A：b + c + a 步到交点。两者相等。

提示 3不相交的情况点开

没有交点时，两个指针都走了 (a + c) + (b + c) 步后同时变成空，循环也会结束，返回空。

所以走到末尾时要走到空再换链表，不能在最后一个节点就换。

代码标准解法：双指针换路点开 
class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        pa, pb = headA, headB
        while pa is not pb:
            pa = pa.next if pa else headB   # 走到空就换到 B 的头
            pb = pb.next if pb else headA
        return pa                       # 交点，或者都是空
代码简洁写法：集合（O(m+n) 空间）点开

把 A 的节点都放进集合，B 上第一个在集合里的节点就是交点。比较的是节点本身，不是值。

class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        seen = set()
        while headA:
            seen.add(headA)
            headA = headA.next
        while headB and headB not in seen:
            headB = headB.next
        return headB

写代码时注意

比较的是节点

用 is 判断是不是同一个节点。值相同不代表是同一个节点。

走到空再换

条件是 if pa 而不是 if pa.next。这样不相交时两个指针会同时为空，循环能正常结束。

复杂度

时间 O(m + n)，空间 O(1)。
